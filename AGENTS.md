# AGENTS.md

## Cursor Cloud specific instructions

### Product overview

Single-page **Svenska Polisnyheter AI** app (Vite + React 19 + TypeScript). It polls the Swedish Police public API and uses Google Gemini to generate news articles for a selected county (län). There is no local backend, database, or Docker.

### Services

| Service | Required? | Notes |
|---------|-----------|--------|
| Vite dev server (`npm run dev`, port **3000**, host `0.0.0.0`) | Yes | Only process to start locally |
| `GEMINI_API_KEY` in `.env.local` | Yes for full flow | Injected at build/dev via `vite.config.ts` `define` → `process.env.API_KEY` |
| `https://polisen.se/api/events` | Yes | Browser `fetch`; errors return empty lists |
| Google Gemini API | Yes for articles | Model: `gemini-3-flash-preview` |
| Tailwind CDN / Google Fonts / Picsum | Optional | Styling and placeholder images only |

### Commands

See `README.md` and `package.json`:

- **Install:** `npm install`
- **Dev:** `npm run dev` → http://localhost:3000
- **Build:** `npm run build`
- **Preview prod build:** `npm run preview`
- **Typecheck:** `npx tsc --noEmit` (no `lint` or `test` scripts in this repo)

### Dev server (tmux)

Use a named tmux session so the server survives backgrounding, e.g. session `vite-dev-server`:

```bash
tmux -f /exec-daemon/tmux.portal.conf new-session -d -s vite-dev-server -c /workspace -- bash -lc 'npm run dev'
```

### Environment file

Create `/workspace/.env.local`:

```
GEMINI_API_KEY=your_key_here
```

Restart Vite after changing `.env.local` so `loadEnv` picks up the key.

### Gotchas

1. **`index.html` must include** `<script type="module" src="/index.tsx"></script>` before `</body>`. Without it, Vite serves a blank page (no React mount). Production `npm run build` also omits the JS bundle until this line exists.
2. **No automated tests or ESLint** — validate with `npx tsc --noEmit`, `npm run build`, and manual UI smoke (county select → articles when key + APIs work).
3. **API key is client-bundled** via Vite `define` (AI Studio export pattern); not suitable for production secrets.
4. **`package-lock.json`** is generated by `npm install` and should be committed for reproducible installs.
